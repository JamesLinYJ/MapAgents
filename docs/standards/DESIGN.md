# 地理智能平台桌面设计规范

本文是桌面端设计语言的唯一事实源。界面新增、重构和评审均以本文为准；业务样式只负责领域布局，不得另建颜色、字号、圆角、阴影或窗口安全区体系。

## 一、设计目标

桌面端采用“专业地理工作台”语言：清晰、克制、紧凑、可信。地图和数据是主角，界面负责组织层级与表达状态，不使用网页宣传页式的巨幅标题、过量留白、多套玻璃材质或无语义装饰。

统一遵守以下原则：

1. **桌面优先**：信息密度适合长期操作，不把移动端卡片设计直接放大到桌面。
2. **层级可见**：画布、页面、区块、控件、浮层五级关系由表面、边框和间距表达。
3. **状态真实**：成功、警告、失败和不可用只表达真实业务状态；颜色不能代替文字。
4. **操作一致**：同级按钮、输入框、标签页和卡片拥有一致尺寸与交互反馈。
5. **原生窗口友好**：任何内容不得进入 macOS 窗口控制区或 Windows/Linux 标题栏按钮区。
6. **中文优先**：面向用户的标题、说明、状态和操作使用清晰中文；协议或供应商专名确需保留时才使用英文。

## 二、权威实现

- `app/styles/glass.css`：维护全部 `--ui-*` 语义变量与唯一浮层玻璃材质。
- `app/styles/ui-system.css`：按固定顺序装载领域样式和最终设计系统层。
- `app/styles/ui-foundation.css`：基础控件、桌面外壳和窗口安全区。
- `app/styles/ui-pages.css`：页面壳、页头、内容卡片、表单和操作。
- `app/styles/ui-content.css`：表格、列表、代码、滚动内容和空状态。
- `app/styles/ui-overlays.css`：对话框、弹出菜单和遮罩。
- `shared/components/LiquidGlassLayer.tsx`：只挂载一个浮层折射滤镜。

禁止在组件内写行内颜色；禁止新增与 `--ui-*` 平行的业务调色板。历史类名可以暂时保留，但最终视觉必须由以上权威层收口。

## 三、窗口安全区

标题栏高度固定为 34 像素，并保留可拖动区域。

- macOS：左侧至少预留 78 像素，放置关闭、最小化和缩放按钮；右侧使用普通 8 像素边距。
- Windows/Linux：左侧使用普通 8 像素边距，右侧至少预留 142 像素给系统窗口按钮。
- 首次设置页的品牌栏同样遵守平台安全区，不能把图标或文字放在控制按钮下方。
- 窗口宽度不足时优先隐藏次要说明和文字，不压缩系统控制区。

平台信息由 Preload 桥提供，并写入根节点 `data-desktop-platform`。业务组件不得自行判断用户代理。

## 四、页面骨架

所有工作台内页面使用同一结构：

1. `ui-page`：页面画布，允许纵向滚动。
2. `ui-page__content`：内容容器，最大宽度 1180 像素并水平居中。
3. `ui-page-header`：页头，包含眉题、标题、说明和右侧主要状态或操作。
4. `ui-page-section`：一级内容区块。
5. `ui-card`：区块内部的可选对象或数据卡片。

页面外边距：宽屏 24 像素、普通窗口 18 像素、窄窗口 12 像素。一级区块间距 16 像素；卡片间距 12 像素；控件内部使用 8 像素节奏。

设置、账号、安全、协议、工具和调试页面都必须使用这一骨架。页面不得自行设置另一套背景渐变或最大宽度。

## 五、排版

字体使用系统无衬线字体，代码和标识使用系统等宽字体。

| 层级 | 字号 | 字重 | 用途 |
| --- | ---: | ---: | --- |
| 页面标题 | 28 像素 | 700 | 每页唯一主标题 |
| 区块标题 | 18 像素 | 700 | 一级内容区块 |
| 卡片标题 | 14 像素 | 650 | 对象、服务或结果名称 |
| 正文 | 13 像素 | 400–550 | 说明与数据内容 |
| 辅助文字 | 11–12 像素 | 500–650 | 状态、时间与元数据 |
| 眉题 | 11 像素 | 700 | 页面或区块分类 |

标题最多两级。工作台内禁止使用超过 34 像素的营销式标题；正文行高为 1.55–1.7，长文页面可使用 1.8。

## 六、表面、边框与圆角

- 页面画布：`--ui-canvas` / `--ui-canvas-soft`。
- 页头与一级区块：`--ui-surface`，1 像素 `--ui-border` 边框。
- 次级卡片：`--ui-surface` 或 `--ui-surface-muted`。
- 下沉输入区：`--ui-surface-sunken`。
- 页头圆角：`--ui-radius-lg`（16 像素）。
- 一级区块和卡片：`--ui-radius-md`（12 像素）。
- 控件：`--ui-radius-sm`（8 像素）。
- 标签：`--ui-radius-pill`。

页头最多使用 `--ui-shadow-sm`；普通内容卡片不使用外投影。`--ui-shadow-md` 只用于菜单，`--ui-shadow-lg` 只用于模态浮层。

## 七、颜色与状态

主色 `--ui-accent` 只用于当前选择、焦点、链接和主要操作。大面积内容不能使用高饱和主色背景。

- 成功：`--ui-success` / `--ui-success-soft`
- 警告：`--ui-warning` / `--ui-warning-soft`
- 失败或危险：`--ui-danger` / `--ui-danger-soft`
- 不可用：正文说明配合中性或警告色，不显示绿色指示

状态必须同时提供中文文字、图标或形状提示，不能只依赖颜色。

## 八、控件

- 普通按钮高度 34–36 像素，主要按钮使用实色主色；危险按钮使用危险语义色。
- 输入框、选择框和文本框最小高度 36 像素，标签位于控件上方。
- 同一操作组最多一个主要按钮；“取消”保持次要样式。
- 标签页使用下划线或左侧强调线表达当前项，不使用整块黑色反转。
- 可选择卡片使用边框和浅色背景表达选中，不使用位移或悬浮跳动。
- 禁用控件必须保留可读说明，不能仅降低透明度后让用户猜测原因。

## 九、浮层

只有对话框、弹出菜单和短暂提示可以使用玻璃材质。设置卡片、表格、时间线、日志和侧栏必须使用稳定实色表面。

对话框必须：

- 固定在视口中央；
- 最大高度不超过视口减 32 像素；
- 内容超出时只在对话框正文中纵向滚动；
- 装饰伪元素不得扩大滚动范围；
- 打开后焦点进入浮层，Tab 不离开浮层，Esc 在无未保存内容时关闭。

## 十、响应式与无障碍

- 1024×700 是最低桌面窗口尺寸。
- 低于 900 像素时，双列卡片改为单列，页头操作换行。
- 所有键盘操作使用 `:focus-visible`，焦点环使用 `--ui-focus-ring`。
- 动画遵守 `prefers-reduced-motion`；增强对比度和强制色彩模式必须可读。
- 正文与背景满足可读对比度；图标按钮必须有中文可访问名称。

## 十一、禁止事项

- 不新增第二份设计规范或设计变量文件。
- 不在业务页面硬编码新的颜色、圆角、阴影和背景渐变。
- 不把内容卡片包装成多套“玻璃”变体。
- 不使用超大标题、过量圆角、层层阴影或无业务含义的发光效果。
- 不让系统窗口按钮、滚动条或固定操作遮挡内容。
- 不用英文占位词替代已经确定的中文产品文案。

## 十二、验收

视觉改动至少完成：

1. 真实打包 Electron 在 macOS 中检查窗口控制区。
2. 1440×900 与 1024×700 附近窗口检查页面布局。
3. 键盘焦点、Esc、滚动和减少动态效果检查。
4. `npm run test:desktop`、`npm run lint:desktop`、`npm run build:desktop`。
5. 视觉系统测试确认只有一个规范文件、一个语义变量体系和一个浮层玻璃材质。
